⚠️ Should you use this website? No — not this copy.

If you didn't host it yourself, don't paste tokens into it. You should never paste live secrets into a random website, and you shouldn't trust one on blind faith. Yes, you can view source today — but how do you know the author didn't change it (or backdoor it) by the time you come back tomorrow? A static page you read once is not a page you can trust forever. The same goes for pasting JWTs into jwt.io and hoping it "stays in the browser" — that's faith, not verification.

This site is a proof of concept. It works, and you can use the hosted copy if you accept the risk — but if you're worth your salt as a security engineer, you should be hosting it yourself. It's three static files in a public-domain repo: clone it, read every line, run it from disk or with one Docker command, and paste tokens only into the copy you control. See the footer and README for how.

revoke.me

Paste a leaked token. See whose it is. Kill it — from this page, straight to the provider.

This is static code hosted on GitHub Pages — three files (HTML/CSS/JS), no backend, no server, no database. Your browser talks directly to the provider APIs; nothing is sent to any server of ours, because there isn't one. View source and deploy it yourself — it's in the public domain (Unlicense).

These commands are static — they are fixed text, not built from
       anything you type into this page. The token is read interactively by the command itself
       (hidden prompt, never stored, never in shell history). Works on macOS/Linux (bash/zsh)
       and Windows (PowerShell). You don't need to paste anything here to use these.


    

      
GitHub

      

        
        
      

      

        
printf 'GitHub token: ' >&2; read -rs TOKEN && { \
  echo 'Checking token is live...'; \
  curl -sS -o /dev/null -w 'live: HTTP %{http_code}\n' -H "Authorization: Bearer $TOKEN" https://api.github.com/user; \
  echo 'Revoking...'; \
  curl -sS -o /dev/null -w 'revoke: HTTP %{http_code}\n' -X POST https://api.github.com/credentials/revoke -H 'Accept: application/vnd.github+json' -H 'Content-Type: application/json' --data "{\"credentials\":[\"$TOKEN\"]}"; \
  echo 'Confirming dead...'; \
  curl -sS -o /dev/null -w 'after: HTTP %{http_code} (401 = dead)\n' -H "Authorization: Bearer $TOKEN" https://api.github.com/user; \
  }; unset TOKEN

        
202 = revoked. Unauthenticated endpoint — no auth header. GitHub API docs — credentials/revoke Three steps: live check (200), revoke (202), confirm dead (401). If the live check already shows 401, the token is dead — nothing was killed; check you pasted the right key.

      

      

        
$sec = Read-Host -AsSecureString 'GitHub token'; $b = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($sec); try { $TOKEN = [Runtime.InteropServices.Marshal]::PtrToStringAuto($b); 'Checking token is live...'; curl.exe -sS -o NUL -w 'live: HTTP %{http_code}\n' -H "Authorization: Bearer $TOKEN" https://api.github.com/user; 'Revoking...'; [pscustomobject]@{credentials=@($TOKEN)} | ConvertTo-Json -Compress | curl.exe -sS -o NUL -w 'revoke: HTTP %{http_code}\n' -X POST https://api.github.com/credentials/revoke -H 'Accept: application/vnd.github+json' -H 'Content-Type: application/json' --data '@-'; 'Confirming dead...'; curl.exe -sS -o NUL -w 'after: HTTP %{http_code} (401 = dead)\n' -H "Authorization: Bearer $TOKEN" https://api.github.com/user; } finally { if ($b -ne [IntPtr]::Zero) { [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($b) }; $sec.Dispose(); Remove-Variable TOKEN -ErrorAction SilentlyContinue }

        
202 = revoked. Unauthenticated endpoint — no auth header. GitHub API docs — credentials/revoke Three steps: live check (200), revoke (202), confirm dead (401). If the live check already shows 401, the token is dead — nothing was killed; check you pasted the right key.

GitLab (gitlab.com)

      

        
        
      

      

        
printf 'GitLab token: ' >&2; read -rs TOKEN && { \
  echo 'Checking token is live...'; \
  curl -sS -o /dev/null -w 'live: HTTP %{http_code}\n' "https://gitlab.com/api/v4/personal_access_tokens/self?private_token=$TOKEN"; \
  echo 'Revoking...'; \
  curl -sS -o /dev/null -w 'revoke: HTTP %{http_code}\n' -X DELETE "https://gitlab.com/api/v4/personal_access_tokens/self?private_token=$TOKEN"; \
  echo 'Confirming dead...'; \
  curl -sS -o /dev/null -w 'after: HTTP %{http_code} (401 = dead)\n' "https://gitlab.com/api/v4/personal_access_tokens/self?private_token=$TOKEN"; \
  unset TOKEN; }

        
204 = revoked. 401 beforehand = already dead. GitLab API docs — personal access tokens (self-revoke) Three steps: live check (200), revoke (204), confirm dead (401). If the live check already shows 401, the token is dead — nothing was killed.

Google

      

        
        
      

      

        
printf 'Google token: ' >&2; read -rs TOKEN && { \
  echo 'Checking token is live...'; \
  curl -sS -o /dev/null -w 'live: HTTP %{http_code} (access tokens only)\n' "https://oauth2.googleapis.com/tokeninfo?access_token=$TOKEN"; \
  echo 'Revoking...'; \
  curl -sS -o /dev/null -w 'revoke: HTTP %{http_code}\n' -X POST https://oauth2.googleapis.com/revoke --data-urlencode "token=$TOKEN"; \
  echo 'Confirming dead...'; \
  curl -sS -o /dev/null -w 'after: HTTP %{http_code} (400 = dead)\n' "https://oauth2.googleapis.com/tokeninfo?access_token=$TOKEN"; \
  unset TOKEN; }

        
200 = revoked. 400 = already invalid or malformed. Google OAuth docs — token revocation Three steps (access tokens): live check (200), revoke (200), confirm dead (400). Refresh tokens cannot be verified from a client — the live/after lines will not be meaningful.

100% static code, served as-is. No backend, no logging, no persistence — the token
       lives in one JS variable and is wiped on unload (or the Wipe button).

    
Don't trust this host? The whole site is three files in a public-domain repo —
       run it yourself with one Docker command, or just open the files from disk.

    
The CSP on this page allows outbound connections only to
       api.github.com, slack.com, oauth2.googleapis.com, api.dropboxapi.com, and
       gitlab.com — view source; nothing here phones home.
       Full source: github.com/markcunninghamgit/revoke-me

    
GitLab: gitlab.com only (self-hosted instances are out of scope).
